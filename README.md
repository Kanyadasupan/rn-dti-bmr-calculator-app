# 🔥 BMR Calculator App
### Calculate your Basal Metabolic Rate & Daily Calorie Needs ⚡
**Mobile Application developed with React Native Expo**

ยินดีต้อนรับสู่แอปพลิเคชันคำนวณอัตราการเผาผลาญพลังงานพื้นฐาน (BMR Calculator) ตัวช่วยในการดูแลสุขภาพที่ให้คุณประเมินปริมาณแคลอรี่ที่ร่างกายต้องการในแต่ละวันได้อย่างแม่นยำ พร้อมทั้งสามารถเลือกรูปแบบกิจกรรมเพื่อวางแผนการดูแลสุขภาพได้อย่างมีประสิทธิภาพ

---

## ✨ คุณสมบัติหลัก (Features)
* **🔥 BMR Calculation:** คำนวณอัตราการเผาผลาญพลังงานพื้นฐานของร่างกายในขณะพักผ่อน
* **⚡ Activity Level:** ประเมินพลังงานที่ใช้ในแต่ละวันตามระดับกิจกรรม (TDEE - Total Daily Energy Expenditure)
* **📊 Health Planning:** ช่วยในการวางแผนเป้าหมายด้านสุขภาพ ไม่ว่าจะเป็นการลดน้ำหนัก รักษาน้ำหนัก หรือเพิ่มกล้ามเนื้อ
* **🎨 Clean & User-Friendly UI:** อินเทอร์เฟซที่ออกแบบมาให้ใช้งานง่าย กรอกข้อมูลสะดวก ดีไซน์ทันสมัยและสบายตา
* **📱 Responsive Design:** รองรับการทำงานอย่างสมบูรณ์แบบบนสมาร์ทโฟนทุกขนาด ทั้งระบบ iOS และ Android

## 🚀 การติดตั้งและใช้งาน (Setup & Installation)

1.  **Clone โปรเจกต์:**
    ```bash
    git clone [https://github.com/KanyadaSupan/bmr-calculator-app.git](https://github.com/KanyadaSupan/bmr-calculator-app.git)
    cd bmr-calculator-app
    ```
    *(ตรวจสอบและเปลี่ยน URL ของ Repository ให้ตรงกับของคุณ)*

2.  **ติดตั้ง Dependencies:**
    ```bash
    npm install
    ```

3.  **รันแอปพลิเคชัน:**
    ```bash
    npx expo start
    ```
    *จากนั้นสแกน **QR Code** ผ่านแอป **Expo Go** บนมือถือของคุณ (iOS/Android)*
